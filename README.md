# tactical-strike-online
Tactical Strike Online, Counter-Strike tarzından ilham alan, tarayıcı üzerinden oynanabilen çevrim içi çok oyunculu FPS oyunudur.

🎮 Özellikler:
- Çevrim içi çok oyunculu oyun
- Bilgisayar ve telefon desteği
- PS4 oyun kolu desteği
- Silah değiştirme ve şarjör sistemi
- Gerçekçi silah sesleri
- Mini Gun
- Taktiksel savaş haritaları

Platform: Web / Python Server
